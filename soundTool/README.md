# Beast2D Sound Tool

A standalone PixiJS 8 + TypeScript + Vite canvas starter with a fixed 320 × 240 render resolution. This folder has its own package manifest and does not import the Beast2D engine.

## Run

```sh
cd soundTool
pnpm install
pnpm dev
```

## Verify a production build

```sh
pnpm build
pnpm preview
```
